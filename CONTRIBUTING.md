# Contributing To San
Thank you for contributing to San!

## Reporting Bugs
Before opening an issue:
- Check if the problem has already been reported
- Include San version and Python Version
- Provide a minimal example that reproduces the bug

## Suggesting Features
Feature requests are welcome. Please explain:
- What problem the feature solves
- Why it might be useful
- An example of how it might work

## Development Setup
```
git clone https://github.com/anubhav-1207/san
cd san
pip install -r requirements.txt
```

## Code Philosphy
- Follow PEP 8
- Use clear and descriptive names
- Comments whenever necessary
- Keep changes small and focused
- One PR, One Improvement

## Testing
Before submitting a pull request, make sure 
- to include your `tests.py` file
- it passes all tests

## Pull Requests
1. Fork the repo
2. Create a new branch
3. Make & test your changes 
4. Submit your PR 

Please keep your PR small and focused

## PR Guidelines
- One feature or fix per PR
- Update documentation if needed
- Ensure it doesn't break other parts
- Be open to feedback and requested changes


# Code of Conduct
By participating in this project, you agree to be respectful and constructive.

Thank you for improving San.
